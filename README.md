# Ubuntu_VM_Setup.sh
Self made setup script for simplifying the creation of a VM. Built for use on debian/ubuntu based linux systems, comments and code should be easy to read and modify based on user prefernces/hardware.
* FEATURES:
* Checks for image files and virtual disks
* Automatically moves iso's from ~/Downloads to libvirt's working directory
* Displays system resources for proper VM configuration
* Easy to use User Prompts (ex. [Enter VM Name: {fsociety}]
